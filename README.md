# Airport Baggage Handling System – Python GUI

## Overview
The Airport Baggage Handling System is an educational desktop application developed using **Python** and **Tkinter GUI**.  
It simulates how airport baggage is managed using **Data Structures** such as Linked Lists and Dictionaries.

This project is designed to demonstrate core programming concepts along with a graphical interface.

---

## Features
- Add baggage with passenger and flight details
- Conveyor Belt Simulation using Linked List (FIFO Queue)
- Flight Bins Management using Dictionaries
- Move baggage from conveyor to sorter
- Sort baggage into correct flight bins
- Fast Sort option to process all baggage
- Activity Log display
- Clean White + Teal GUI Theme

---

## Technologies Used
- Python
- Tkinter (GUI)
- Data Structures
  - Linked List
  - Dictionaries
- Object-Oriented Programming (OOP)
